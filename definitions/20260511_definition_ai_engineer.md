# AI Engineer

## Definition

An AI engineer is an agentic software assistant that helps with software development by reading project context, proposing implementation steps, editing files, running commands, and reporting results.
Unlike a simple chatbot, an AI engineer is usually connected to tools such as a terminal, file system, browser, package manager, or source-control workflow.

## Context and Usage

AI engineers are used for tasks such as scaffolding projects, debugging errors, writing tests, producing documentation, and automating repetitive development work. They are most useful when they run in a controlled development environment where code changes can be reviewed before they are merged.

Remote sandboxes and development containers are common companions for AI engineers. The sandbox isolates the experiment, while the development container defines the runtime, dependencies, and setup commands needed to reproduce the work.
